## Tools Summary

All tools are free, browser-based, require no login and no API keys.

### 1. Meta Tag Extractor
Paste up to 50 URLs. Extracts: page title, meta description, H1, canonical tag, OG tags (og:title, og:description, og:image), Twitter card tags, robots meta, and more. Exports a structured Excel file. Works on JavaScript-rendered (SPA) sites via a proxy chain fallback.

### 2. SERP Preview Tool
Shows a pixel-accurate preview of how a page title and meta description appear in Google Search results on both desktop and mobile. Includes a mobile phone-frame view and pixel-width indicators.

### 3. SERP Simulator
Simulate Google search snippets before publishing. Real-time pixel count for title (limit: 600px) and meta description (limit: 960px). Shows warning when truncation will occur.

### 4. Content Readability Analyzer
Analyses content for Flesch-Kincaid reading ease score, keyword density, passive voice percentage, average sentence length, and readability grade. Powered by a Python backend deployed on Vercel.

### 5. Duplicate Content Checker
Compares two pages using TF-IDF cosine similarity and Jaccard character-level scoring. Highlights matching sentences side-by-side, recommends which URL to canonicalise, and generates the exact `<link rel="canonical">` tag to copy.
